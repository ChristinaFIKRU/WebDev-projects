About the Project

What is this about?

Randomized Particles is a generative visual study of particle behavior — an attempt to capture what it feels like for elements to interact within a system: the overlapping paths, the density of movement, the rhythm of change.

Each run of the sketch produces something unique. Particles emerge, drift, collide, and leave traces — mimicking the way a system leaves marks on the elements that pass through it. The longer you watch, the more patterns emerge from what first appears to be noise.

The color palette draws from golden-hour light that specific amber glow that makes even the most ordinary street feel cinematic. Distance, density, and direction all influence how each particle behaves.

How it works

The Core Idea

The sketch uses a Perlin noise flow field to give each particle a direction at every point in space. Particles follow these invisible currents, leaving semi-transparent trails that accumulate over time.

The result feels organic because Perlin noise produces smooth, continuous variation — unlike random noise, it changes gradually, the same way wind or water currents shift.

01
Spawn particles at random positions along the canvas edges, simulating pedestrians entering the city frame.
02
Sample the noise field at each particle's position to get a direction angle, then move the particle along that vector.
03
Draw a small semi-transparent stroke between the particle's previous and current position, building up trail density over time.
04
Age each particle — older particles fade and eventually die, replaced by fresh ones. The city is always in motion.
sketch.js
// Walk Through the Streets — p5.js sketch
// Perlin noise flow field + particle trails

let particles = [];
let noiseScale = 0.003;
let noiseStrength = 2.0;
let particleCount = 600;
let zOffset = 0;

function setup() {
  createCanvas(windowWidth, windowHeight);
  background(10, 10, 10);
  colorMode(HSB, 360, 100, 100, 100);

  // spawn initial particles
  for (let i = 0; i < particleCount; i++) {
    particles.push(new Particle());
  }
}

function draw() {
  // ghost trail — don't clear fully
  background(0, 0, 4, 8);

  for (let p of particles) {
    p.update();
    p.draw();
    if (p.isDead()) p.reset();
  }

  zOffset += 0.001; // slow time drift
}

class Particle {
  constructor() { this.reset(); }

  reset() {
    this.x  = random(width);
    this.y  = random(height);
    this.px = this.x;
    this.py = this.y;
    this.age = 0;
    this.maxAge = random(80, 300);
    this.speed = random(1.2, 2.8);
    this.hue = random(30, 50); // amber-gold range
  }

  update() {
    let angle = noise(
      this.x * noiseScale,
      this.y * noiseScale,
      zOffset
    ) * TWO_PI * noiseStrength;

    this.px = this.x;
    this.py = this.y;
    this.x += cos(angle) * this.speed;
    this.y += sin(angle) * this.speed;
    this.age++;
  }

  draw() {
    let alpha = map(
      this.age, 0, this.maxAge, 60, 0
    );
    stroke(this.hue, 60, 90, alpha);
    strokeWeight(0.8);
    line(this.px, this.py, this.x, this.y);
  }

  isDead() {
    return (
      this.age > this.maxAge ||
      this.x < 0 || this.x > width ||
      this.y < 0 || this.y > height
    );
  }
}

function windowResized() {
  resizeCanvas(windowWidth, windowHeight);
  background(0, 0, 4);
}
